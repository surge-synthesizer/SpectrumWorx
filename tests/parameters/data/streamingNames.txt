# Regenerate with SW_STREAMING_NAMES_UPDATE=1 ./sw-tests "[streaming-names]"

#   These are the strings that go *into a file*: the keys a preset and a
#   session state are written under, and matched by on the way back in. They
#   are not the strings a user sees -- see parameterTable.txt for those.
#
#   A row that moves is a file on someone's disk that stops being understood:
#   the parameter it names loads its default instead, silently. Renaming a
#   knob or retitling an effect must therefore be paired with a
#   STREAMING_NAME / LE_SW_EFFECT_STREAMING_NAME pin, which holds the file key
#   still and leaves this table alone.
#
# effect/<index> | <streaming name> | <title>
#     what a preset calls the effect, and what a user sees. Equal unless the
#     title has moved since presets were written naming it.
#
# param/<effect streaming name>/<index> | <streaming name>
# global/<index> | <streaming name>
# lfo/<index> | <streaming name>
#     the module, global and LFO parameter keys. Spaces are written as
#     underscores so that ' | ' stays unambiguous as a column separator.
